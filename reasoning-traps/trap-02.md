# Nested If-Then in Project Scope

**Domain:** Project Management

---

## 🧩 Prompt
If the project includes feature A only when resource X is available, and feature B only if A is not included, which feature is in scope if X is unavailable?

---

## ✅ Correct Answer
Feature B

---
